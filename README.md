# หมูถ่ายรูป

PWA สำหรับตากล้องคอสเพลย์: จัดคิวถ่าย, ดูคิวรายวัน/รายเดือน, จับเวลาพร้อมดูรูป ref, ติดตามงานทุกสถานะ และบันทึกรายรับ

- **React 19 + TypeScript + Vite + Tailwind CSS v4** และ `vite-plugin-pwa` สำหรับ service worker
- ไม่มี backend ข้อมูลอยู่ในเครื่อง (IndexedDB) และสำรองไว้ใน Google Drive ของตากล้องเอง
- ติดตั้งลงหน้าจอหลักได้ และเปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต

## เริ่มใช้งาน

```bash
pnpm install
pnpm dev          # http://localhost:5173 (เปิดจากมือถือในวง Wi-Fi เดียวกันได้ด้วย ดู URL "Network")
```

คำสั่งอื่น:

```bash
pnpm build        # สร้างไฟล์สำหรับ deploy ไว้ใน dist/
pnpm preview      # เปิดดู dist/ แบบเดียวกับตอนขึ้นเว็บจริง (service worker ทำงานเฉพาะโหมดนี้และบนเว็บจริง)
pnpm typecheck    # ตรวจ TypeScript
```

ต้องใช้ Node 20 ขึ้นไป

## โครงสร้าง

```
index.html                 หน้าเริ่มต้นของ Vite
vite.config.ts             ปลั๊กอิน React, Tailwind, PWA (manifest อยู่ในไฟล์นี้)
public/                    ไอคอนแอปและมาสคอต (ก๊อปไปตรงๆ ตอน build)
src/
  main.tsx                 จุดเริ่มต้น: โหลดข้อมูลจากเครื่อง แล้ว render <App/>
  App.tsx                  โครงแอป: หัวแอป เมนูล่าง แถบ "กำลังถ่าย" เมนู ⋯ ป๊อปอัป ข้อความแจ้ง
  index.css                Tailwind + สีของธีม (CSS variables) + คอมโพเนนต์ที่ใช้ซ้ำ
  views/                   หน้าหลัก: Today, Jobs (งานทั้งหมด), Calendar, Money (รายรับ), Settings, Session (หน้าถ่าย)
  components/              การ์ดคิว, รูป ref/ภาพเลื่อนวนรอบ, ปุ่มและป้ายต่างๆ
  sheets/                  ป๊อปอัปจากด้านล่าง: ฟอร์มเพิ่ม/แก้ไขคิว, บันทึกเงิน, ยืนยันต่างๆ, ตั้งค่า
  lib/
    types.ts               โครงข้อมูล: Booking (คิว) → Slot (ช่วงเวลา) → Shot (ช็อต) / Ref (รูป)
    model.ts               สถานะงาน, คำนวณเวลา, ตัวช่วยอ่านข้อมูล
    store.ts               state ของแอป (object เดียว + useSyncExternalStore)
    actions.ts             ทุกการกระทำที่แก้ข้อมูล
    persist.ts             บันทึก/โหลดจาก IndexedDB, ย่อรูปที่อัปโหลด
    drive.ts               เข้าสู่ระบบ Google, ซิงก์, สร้างโฟลเดอร์ Ref
    now.ts                 นาฬิกากลางสำหรับตัวจับเวลา (เดินเฉพาะตอนมีคิวกำลังจับเวลา)
    sample.ts, refart.ts   ข้อมูลตัวอย่างและภาพท่าโพสที่วาดด้วยโค้ด
```

**หลักของ state:** ข้อมูลทั้งหมดอยู่ใน `S` (ใน `store.ts`) คอมโพเนนต์อ่านผ่าน `useApp()` ส่วนการแก้ข้อมูลทำใน `actions.ts` แล้วเรียก `commit()` ซึ่งจะ render ใหม่และบันทึกลงเครื่องอัตโนมัติ (และขึ้น Drive ถ้าเข้าสู่ระบบอยู่)

**ตัวจับเวลา** เก็บเป็นเวลาเริ่ม (timestamp) ไม่ใช่ตัวนับ จึงเดินต่อถูกต้องแม้ปิดแอปหรือรีเฟรช

## ตั้งค่า Google Drive

ถ้ายังไม่ตั้งค่า แอปก็ใช้งานได้ตามปกติ ข้อมูลเก็บในเครื่องอย่างเดียว

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่
2. **APIs & Services → Library** ค้นหา **Google Drive API** แล้วกด Enable
3. **APIs & Services → OAuth consent screen**
   - User type: **External**, ใส่ชื่อแอปและอีเมลติดต่อ
   - Scopes: `.../auth/drive.file`, `openid`, `email`, `profile`
   - Test users: ใส่อีเมล Google ที่จะใช้ (ระหว่างสถานะ Testing มีแค่คนในรายการนี้ที่เข้าสู่ระบบได้)
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**
   - Application type: **Web application**
   - Authorized JavaScript origins:
     - `http://localhost:5173` (pnpm dev)
     - `http://localhost:4173` (pnpm preview)
     - โดเมนจริงตอน deploy เช่น `https://<ชื่อ>.github.io`
   - ไม่ต้องใส่ Redirect URI
5. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ Client ID:

   ```
   VITE_GOOGLE_CLIENT_ID=1234567890-xxxxxxxx.apps.googleusercontent.com
   ```

6. หยุดแล้วรัน `pnpm dev` ใหม่ (Vite อ่านไฟล์ .env ตอนเริ่มเท่านั้น) → แท็บ **ตั้งค่า** → **เข้าสู่ระบบ**

ตอน deploy ให้ตั้งตัวแปร `VITE_GOOGLE_CLIENT_ID` ในหน้าตั้งค่าของ hosting ด้วย (Client ID ไม่ใช่ความลับ ใส่ในโค้ดฝั่งเว็บได้)

### ข้อมูลใน Drive

```
หมูถ่ายรูป/
  data.json                    คิว การเงิน การตั้งค่า (และรูป ref ที่อัปโหลดจากเครื่อง)
  ref/
    <ชื่อลูกค้า · วันที่>/       โฟลเดอร์ Ref ของแต่ละคิว แชร์แบบ "ทุกคนที่มีลิงก์แก้ไขได้"
```

- **การซิงก์:** แก้ข้อมูลแล้วแอปบันทึกขึ้น Drive เองภายในไม่กี่วินาที (ระหว่างที่ยังเข้าสู่ระบบอยู่) ปุ่ม **ซิงก์ตอนนี้** ใช้ดึงข้อมูลจากเครื่องอื่น
- **แก้สองเครื่อง:** ใช้ไฟล์ที่บันทึกล่าสุดทั้งไฟล์ ถ้าแก้สองเครื่องโดยไม่ซิงก์ก่อน ข้อมูลของเครื่องที่บันทึกก่อนจะถูกแทนที่ ควรกดซิงก์ก่อนเริ่มใช้อีกเครื่อง
- Token ของ Google มีอายุราว 1 ชั่วโมง หลังจากนั้นกดซิงก์อีกครั้งเพื่อต่ออายุ

### รูปที่คอสเพลเยอร์อัปโหลดเข้าโฟลเดอร์ Ref

ค่าเริ่มต้นใช้สิทธิ์ `drive.file` แอปเห็นเฉพาะไฟล์ที่แอปสร้างเอง จึง **มองไม่เห็นรูปที่คอสเพลเยอร์อัปโหลดเข้ามา** ตากล้องเปิดดูได้จากปุ่ม "เปิดโฟลเดอร์"

ถ้าอยากให้แอปดึงรูปเหล่านั้นมาเป็น ref ของคิวอัตโนมัติ:

1. ใน `.env.local` ตั้ง `VITE_READ_REF_UPLOADS=true`
2. เพิ่ม scope `.../auth/drive.readonly` ใน OAuth consent screen
3. รัน dev ใหม่ แล้วออกจากระบบและเข้าใหม่หนึ่งครั้ง

`drive.readonly` เป็น restricted scope ใช้เองหรือกับ test users ได้ทันที ถ้าจะเปิดให้คนทั่วไปใช้ต้องผ่านการตรวจสอบของ Google

## Deploy

ต้องเป็น HTTPS ถึงจะติดตั้งเป็นแอปได้ `pnpm build` แล้วอัปโหลดโฟลเดอร์ `dist/` ขึ้น static hosting ไหนก็ได้ (Netlify, Vercel, Cloudflare Pages, GitHub Pages) ตั้งค่า build command = `pnpm build`, output = `dist`

`base: './'` ใน `vite.config.ts` ทำให้ใช้ได้ทั้งบนโดเมนหลักและ sub-path เช่น GitHub Pages `/repo-name/`

service worker อัปเดตตัวเองเมื่อมีเวอร์ชันใหม่ ไม่ต้องเปลี่ยนเลขเวอร์ชันเอง

## ข้อจำกัดที่ควรรู้

- เสียงเตือนตัวจับเวลาดังเฉพาะตอนแอปเปิดอยู่
- รูป ref ที่อัปโหลดจากเครื่องถูกย่อเหลือด้านยาวไม่เกิน 1400px และเก็บรวมใน `data.json` ถ้ารูปเยอะมาก ไฟล์จะใหญ่และซิงก์ช้าลง (ใช้ลิงก์รูปหรือโฟลเดอร์ Ref แทนได้)
- ลิงก์ที่ชี้ไปหน้าเว็บ (เช่นหน้าพิน Pinterest) แสดงเป็นรูปไม่ได้ ต้องกดเปิดลิงก์ ลิงก์ที่ชี้ไปไฟล์รูปโดยตรงจะแสดงเป็นรูป
- ยังไม่มีการแจ้งเตือนล่วงหน้าตอนปิดแอป (ต้องมีเซิร์ฟเวอร์)

## ย้ายข้อมูลจากเวอร์ชัน HTML เดิม

ข้อมูลของเวอร์ชันเดิม (ไฟล์ HTML/JS ล้วน) เปิดในเวอร์ชันนี้ได้ ถ้าเคยซิงก์ขึ้น Drive ไว้ แค่เข้าสู่ระบบบัญชีเดิมแล้วกด "ซิงก์ตอนนี้" ไฟล์เวอร์ชันเดิมย้ายไปเก็บไว้ที่ `_old-static/` ลบทิ้งได้เมื่อไม่ต้องใช้แล้ว
