# หมูถ่ายรูป

PWA สำหรับตากล้องคอสเพลย์: จัดคิวถ่าย, ดูคิวรายวัน/รายเดือน, จับเวลาพร้อมดูรูป ref, ติดตามงานค้างส่ง และบันทึกรายรับ

- ไม่มี backend ข้อมูลอยู่ในเครื่อง (IndexedDB) และสำรองไว้ใน Google Drive ของตากล้องเอง
- เป็น HTML/CSS/JS ล้วน ไม่ต้อง build ไม่ต้อง `npm install`
- ติดตั้งลงหน้าจอหลักได้ และเปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต (Drive จะซิงก์เมื่อกลับมาออนไลน์และกดซิงก์)

## โครงสร้างไฟล์

```
index.html              หน้าแอป
manifest.webmanifest    ข้อมูลสำหรับติดตั้งเป็นแอป (ชื่อ ไอคอน สี)
sw.js                   service worker: แคชไฟล์แอปไว้ใช้ออฟไลน์
css/app.css             สไตล์ทั้งหมด (สีเป็นตัวแปรใน :root, ธีมมืดใช้ [data-theme="dark"])
js/config.js            ตั้งค่า Google Client ID และตัวเลือก Drive  ← แก้ไฟล์นี้
js/app.js               หน้าจอและการทำงานหลัก
js/store.js             บันทึก/โหลดข้อมูลในเครื่อง (IndexedDB) + ย่อรูปที่อัปโหลด
js/drive.js             เข้าสู่ระบบ Google, ซิงก์ data.json, สร้างโฟลเดอร์ Ref
js/sample.js            ข้อมูลตัวอย่าง (โหลดจากหน้าตั้งค่าเท่านั้น)
js/refart.js            ภาพท่าโพสที่วาดด้วยโค้ด ใช้กับข้อมูลตัวอย่าง
js/main.js              จุดเริ่มต้นของแอป
icons/                  ไอคอนแอป
```

## รันในเครื่อง

service worker และ Google sign-in ไม่ทำงานถ้าเปิดไฟล์ `index.html` ตรงๆ ต้องเปิดผ่าน web server เลือกวิธีใดวิธีหนึ่ง:

```bash
# Python
python -m http.server 8080

# หรือ Node
npx serve -l 8080 .
```

แล้วเปิด http://localhost:8080

ใน VS Code ใช้ส่วนขยาย Live Server ก็ได้ (พอร์ตเริ่มต้น 5500 ต้องเพิ่ม origin นี้ใน Google Cloud ด้วย ดูด้านล่าง)

## ตั้งค่า Google Drive

ถ้ายังไม่ตั้งค่า แอปก็ใช้งานได้ตามปกติ ข้อมูลเก็บในเครื่องอย่างเดียว

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่
2. **APIs & Services → Library** ค้นหา **Google Drive API** แล้วกด Enable
3. **APIs & Services → OAuth consent screen**
   - User type: **External**
   - ใส่ชื่อแอป (หมูถ่ายรูป) และอีเมลติดต่อ
   - Scopes: เพิ่ม `.../auth/drive.file`, `openid`, `email`, `profile`
   - Test users: ใส่อีเมล Google ที่จะใช้ทดสอบ (ระหว่างที่แอปอยู่ในสถานะ Testing มีแค่คนในรายการนี้ที่เข้าสู่ระบบได้)
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**
   - Application type: **Web application**
   - Authorized JavaScript origins: ใส่ทุกที่อยู่ที่จะเปิดแอป เช่น
     - `http://localhost:8080`
     - `http://127.0.0.1:5500` (ถ้าใช้ Live Server)
     - `https://<ชื่อ>.github.io` หรือโดเมนจริงตอน deploy
   - ไม่ต้องใส่ Redirect URI
5. คัดลอก **Client ID** ไปใส่ใน `js/config.js`:

```js
GOOGLE_CLIENT_ID: '1234567890-xxxxxxxx.apps.googleusercontent.com',
```

6. เปิดแอป → แท็บ **ตั้งค่า** → **เข้าสู่ระบบ**

### ข้อมูลใน Drive

```
หมูถ่ายรูป/
  data.json                       คิว การเงิน การตั้งค่า (และรูป ref ที่อัปโหลดจากเครื่อง)
  ref/
    <ชื่อลูกค้า · วันที่>/          โฟลเดอร์ Ref ของแต่ละคิว แชร์แบบ "ทุกคนที่มีลิงก์แก้ไขได้"
```

- **การซิงก์:** แก้ข้อมูลแล้วแอปจะบันทึกขึ้น Drive เองภายในไม่กี่วินาที (ถ้ายังเข้าสู่ระบบค้างอยู่) ปุ่ม **ซิงก์ตอนนี้** ใช้ดึงข้อมูลจากเครื่องอื่น
- **กติกาเมื่อแก้สองเครื่อง:** ใช้ไฟล์ที่บันทึกล่าสุดทั้งไฟล์ ถ้าแก้สองเครื่องพร้อมกันโดยไม่ซิงก์ก่อน ข้อมูลของเครื่องที่บันทึกก่อนจะถูกแทนที่ ควรกดซิงก์ก่อนเริ่มใช้อีกเครื่อง
- Token ของ Google มีอายุราว 1 ชั่วโมง หลังจากนั้นกดซิงก์อีกครั้งเพื่อต่ออายุ (ปกติไม่ต้องกรอกรหัสใหม่)

### รูปที่คอสเพลเยอร์อัปโหลดเข้าโฟลเดอร์ Ref

ค่าเริ่มต้นใช้สิทธิ์ `drive.file` ซึ่งปลอดภัยที่สุด แอปเห็นเฉพาะไฟล์ที่แอปสร้างเอง จึง **มองไม่เห็นรูปที่คอสเพลเยอร์อัปโหลดเข้ามา** ตากล้องเปิดดูได้จากปุ่ม "เปิดโฟลเดอร์" ใน Drive

ถ้าอยากให้แอปดึงรูปเหล่านั้นมาเป็น ref ของคิวอัตโนมัติ:

1. ใน `js/config.js` ตั้ง `READ_REF_UPLOADS: true`
2. เพิ่ม scope `.../auth/drive.readonly` ใน OAuth consent screen
3. ออกจากระบบแล้วเข้าใหม่หนึ่งครั้ง เพื่อให้สิทธิ์ใหม่

`drive.readonly` เป็น restricted scope ใช้เองหรือแจกให้ test users ได้เลย แต่ถ้าจะเปิดให้คนทั่วไปใช้ ต้องผ่านการตรวจสอบของ Google

## Deploy

ต้องใช้ HTTPS ถึงจะติดตั้งเป็นแอปได้ อัปโหลดทั้งโฟลเดอร์ไปที่ static hosting ไหนก็ได้ เช่น GitHub Pages, Netlify, Vercel, Cloudflare Pages แล้วเพิ่มโดเมนนั้นใน Authorized JavaScript origins

**ทุกครั้งที่แก้ไฟล์ใดๆ** ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น `v1.0.1`) ไม่อย่างนั้นมือถือที่ติดตั้งไว้จะยังใช้ไฟล์เก่าจากแคช

## ข้อจำกัดที่ควรรู้

- ตัวจับเวลาเดินระหว่างที่แอปเปิดอยู่ ถ้าปิดแอปแล้วเปิดใหม่ เวลาจะคำนวณต่อให้ถูก แต่เสียงเตือนดังเฉพาะตอนแอปเปิดอยู่
- รูป ref ที่อัปโหลดจากเครื่องถูกย่อเหลือด้านยาวไม่เกิน 1400px แล้วเก็บรวมใน `data.json` ถ้ารูปเยอะมาก ไฟล์จะใหญ่และซิงก์ช้าลง (ใช้ลิงก์รูปหรือโฟลเดอร์ Ref แทนได้)
- ลิงก์รูปที่ชี้ไปหน้าเว็บ (เช่นหน้าพิน Pinterest) แสดงเป็นรูปไม่ได้ ต้องกดเปิดลิงก์ ลิงก์ที่ชี้ไปไฟล์รูปโดยตรงจะแสดงเป็นรูป
- ยังไม่มีการแจ้งเตือนล่วงหน้าตอนปิดแอป (ต้องมีเซิร์ฟเวอร์)
